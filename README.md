# NexGear — E-Commerce SDLC Project

Semester project for the E-Commerce course covering the complete Software Development Life Cycle (SDLC) across 6 sprints, from initial system architecture to final production deployment.

## Repository Structure
* `/docs/` — Sprint documentations, architecture specifications, and diagrams.
* `/src/` — Application source code.

## Sprints Roadmap
- [x] **Sprint 1:** System Architecture & Scope Definition (`/docs/SPRINT_1.md`)
- [ ] **Sprint 2:** Database Implementation & Auth Scaffolding
- [ ] **Sprint 3:** Catalog & Search Implementation
- [ ] **Sprint 4:** Shopping Cart & State Management
- [ ] **Sprint 5:** Checkout & Payment Integration
- [ ] **Sprint 6:** Deployment, Testing & Final Documentation
